# 전승 레인저 공략 개편

2026-11-04 / 대상: `/tip-board/15`

## 이번 작업

- 전승 레인저 한 편을 새 공략의 기준 화면으로 구현했다. 나머지 20개 공략은 기존 화면을 유지한다.
- 원문 작성자 홍줭, 작성 당시 소속 아지다하카 길드 표기를 보존했다. 실제 작성 날짜와 현재 패치 검증 여부는 미확인으로 표시한다.
- 본문 7개 구역과 소제목 28개를 추출하고, 참고 영상을 포함한 8개 목차로 구성했다. 추출 시 각 구역의 본문 텍스트 노드를 원본과 비교하여 동일함을 확인했다.
- 원문 이미지·영상·외부 클립 주소 29개의 보존 여부를 대조했고, 참조된 로컬 이미지 파일이 모두 존재함을 확인했다.
- 첫 화면에 원문을 바탕으로 한 세 가지 읽기 안내와 주 사용 풀콤보 8단계 요약을 추가했다. 세부 원문과 주의사항도 본문에 남겨 두었다.
- PC에서는 고정 목차, 모바일에서는 펼치는 목차를 제공한다. 목차 검색으로 단명·특화 등 해당 소제목에 바로 이동할 수 있다.
- 기존 본문 내부의 생존·단명·우직·초바모 바로가기를 유지했다.
- 이미지 확대는 네이티브 dialog를 사용한다. 확대·축소 버튼, Escape 닫기, 초점 복귀, 배경 스크롤 잠금을 제공한다.
- 후속 피드백 반영: 작성자 제공 `홍줭.png`를 접힌 자료 영역에서 상단 대표 이미지로 이동했다. 클래스 기본 이미지는 상단에서 제거했다. PC·모바일 모두 원본 비율을 유지하고 자르지 않으며, 모바일에서는 제목 아래 전체 너비로 표시한다.
- 임베드 영상은 클릭해야 불러온다. 외부 클립 링크와 이미지 자료는 보존한다.
- 후속 피드백 반영: YouTube 클립 4개를 작은 썸네일·제목·새 탭 안내로 이루어진 가로형 카드로 교체했다. 크게 늘어나던 SVG와 중복 안내 영역을 제거했으며, 원래 클립 주소와 썸네일은 유지했다. 320~1920px 검사에서 각 클립 카드 높이가 160px 미만임을 확인한다.

## 코드 구성

- `lib/portal/guide-content/ranger.tsx`: 서버에서 표시하는 공략 본문과 소제목 정보.
- `components/portal/guide/GuideArticle.tsx`: 공통 공략 화면.
- `GuideNavigation.tsx`, `GuideImage.tsx`, `GuideVideo.tsx`: 조작이 필요한 부분만 클라이언트 컴포넌트로 분리.
- `app/tip-board/components/RangerGuide.tsx`: 전승 레인저 소개, 요약, 작성자 정보 조합.
- `scripts/check-ranger.cjs`: 해당 공략의 브라우저 검사.

## 검증 결과

- 타입 검사·프로덕션 빌드·포맷 검사·공백 검사 통과.
- Chromium에서 320·390·768·1440·1920px 화면 확인. 가로 넘침 없음.
- 8개 본문 구역·28개 소제목, 모든 내부 링크 대상, 목차 검색, 모바일 목차 이동 검사 통과.
- 이미지 열기·확대·Escape 닫기·스크롤 잠금 해제 검사 통과.
- 한글 이미지 경로의 미리 불러오기 헤더 오류를 수정했다. 확대 원본은 창을 열기 전에는 생성하지 않아 불필요한 로딩도 방지한다.
- 최초 iframe 0개, 영상 버튼을 누른 후 iframe 생성 확인.
- 클라이언트 실행 오류 및 중첩 버튼·링크 없음.

외부 영상 재생·링크 생존 여부 및 게임 패치에 따른 공략 내용의 정확성은 이번 검증에 포함하지 않았다. 조회수·추천·댓글 등의 서버 기능도 이번에 추가하지 않았다.
