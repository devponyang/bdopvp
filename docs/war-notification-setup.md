# 전쟁 알림 시스템 설정 가이드

## 개요
전쟁 기록이 업데이트될 때마다 치지직 방송인에게 실시간 알림을 보내는 시스템입니다.

## 기능
- 어드민에서 전쟁 기록 저장 시 자동 알림 전송
- Discord 웹훅을 통한 알림
- OBS 브라우저 소스를 통한 화면 알림 표시

## 설정 방법

### 1. 환경 변수 설정
`.env.local` 파일에 다음 환경 변수를 추가하세요:

```env
# Discord 웹훅 URL (선택사항)
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/YOUR_WEBHOOK_ID/YOUR_WEBHOOK_TOKEN

# OBS 웹소켓 URL (선택사항)
OBS_WEBSOCKET_URL=ws://localhost:4455
```

### 2. Discord 웹훅 설정 (선택사항)
1. Discord 서버에서 웹훅을 생성하세요
2. 웹훅 URL을 `DISCORD_WEBHOOK_URL`에 설정하세요
3. 전쟁 기록 저장 시 Discord 채널에 알림이 전송됩니다

### 3. OBS 브라우저 소스 설정
1. OBS Studio에서 브라우저 소스를 추가하세요
2. URL을 다음과 같이 설정하세요:
   ```
   http://bdopvp.com/api/notifications/war-alert/live
   ```
3. 크기를 600x100으로 설정하세요
4. 자동 새로고침 지원 (수동 새로고침 불필요)

### ⏰ 시간대별 동작
- **20:45-21:00**: "거점전 진행 예정입니다" 표시 (30초마다 새로고침)
- **21:00-22:00**: 진행중인 연맹 표시 (10초마다 로테이션)
- **그 외 시간**: 아무것도 표시하지 않음 (서버 부하 방지)
- **점령 성공**: 즉시 알림 표시 (10초간 유지)

### 4. 실시간 알림 테스트
다음 API를 호출하여 알림을 테스트할 수 있습니다:

```bash
curl -X POST http://bdopvp.com/api/notifications/war-alert/live \
  -H "Content-Type: application/json" \
  -d '{
    "alliance_name": "테스트연맹",
    "region": "칼페온",
    "occupied_area": "칼페온성",
    "fort_stage": "1단계",
    "war_type": "거점전",
    "tier": "무제한"
  }'
```

## 알림 메시지 형식
```
[지역 아이콘] 칼페온 - 테스트연맹 연맹이 1단계 칼페온성을 점령하였습니다.
```

## OBS 브라우저 소스 특징
- **점령 성공**: 10초간 표시 후 자동으로 사라짐
- **진행 예정**: 보라색 그라데이션 배경
- **진행중**: 빨간색 그라데이션 배경
- 슬라이드 인 애니메이션과 페이드 아웃 효과
- 지역별 아이콘과 색상 구분
- 연맹명, 지역명, 단계명에 각각 다른 색상 적용

## 문제 해결
1. **Discord 알림이 안 오는 경우**: 웹훅 URL이 올바른지 확인하세요
2. **OBS에서 알림이 안 보이는 경우**: 브라우저 소스 URL이 올바른지 확인하세요
3. **알림이 너무 자주 오는 경우**: 어드민에서 저장할 때만 알림이 전송됩니다

## 확장 가능한 기능
- 특정 연맹만 알림 받기
- 알림 소리 추가
- 알림 히스토리 저장
- 웹소켓을 통한 실시간 업데이트
