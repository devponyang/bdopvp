# 비디오 재생 문제 해결 가이드

## 🔍 문제 상황
비디오 플레이어는 표시되지만 재생이 되지 않음

## 🛠️ 적용된 개선사항

### 1. RichTextEditor.tsx 개선
- ❌ `autoplay` 제거: 브라우저 정책으로 인한 자동재생 차단 방지
- ✅ `playsInline` 추가: 모바일에서 전체화면 방지
- ✅ `preload="metadata"` 추가: 비디오 메타데이터 미리 로드
- ✅ 에러 처리 개선: 로딩 실패 시 상세한 에러 메시지 표시
- ✅ 로딩 성공 로그: 콘솔에서 비디오 로딩 상태 확인 가능

### 2. lib/markdown.ts 개선
- ❌ `autoplay` 제거: 자동재생 정책 준수
- ✅ `preload="metadata"` 추가: 성능 최적화

## 🔧 디버깅 방법

### 1단계: 브라우저 개발자 도구 열기
```
F12 키 또는 우클릭 > 검사
```

### 2단계: 콘솔 탭 확인
다음 메시지를 확인하세요:

**성공 시:**
```
✅ 비디오 로딩 성공: /api/images/tip-images/파일명.mov
```

**실패 시:**
```
비디오 로딩 실패: /api/images/tip-images/파일명.mov
```

### 3단계: 네트워크 탭 확인
1. **Network** 탭 클릭
2. 비디오 파일 요청 찾기
3. **Status** 확인:
   - `200`: 파일 로딩 성공
   - `404`: 파일 없음
   - `403`: 접근 권한 없음

### 4단계: 비디오 직접 테스트
1. 비디오 URL을 새 탭에서 직접 열기
2. 브라우저가 비디오를 재생할 수 있는지 확인

## 🎯 가능한 원인과 해결방법

### 원인 1: MOV 파일 브라우저 미지원
**증상:** 비디오 플레이어는 보이지만 재생 버튼이 작동하지 않음

**브라우저별 MOV 지원:**
- ✅ **Safari (Mac)**: 완전 지원
- ⚠️ **Chrome (Windows)**: 제한적 지원 (코덱에 따라 다름)
- ❌ **Firefox**: 대부분 미지원

**해결방법:**
1. **MP4로 변환** (가장 권장)
2. **다른 브라우저에서 테스트** (Safari 권장)
3. **WebM 형식 사용**

### 원인 2: 비디오 파일 손상
**증상:** 로딩은 되지만 재생 시 에러

**해결방법:**
1. 원본 파일이 정상인지 확인
2. 다른 비디오 파일로 테스트
3. 파일을 다시 업로드

### 원인 3: MIME 타입 문제
**증상:** 콘솔에 MIME 타입 관련 에러

**해결방법:**
- 서버에서 올바른 MIME 타입 설정됨
- 문제가 지속되면 서버 재시작

### 원인 4: 네트워크 문제
**증상:** 비디오가 로딩되지 않음

**해결방법:**
1. 네트워크 탭에서 404/500 에러 확인
2. 서버 재시작
3. 파일 경로 확인

## ✅ 테스트 체크리스트

### 기본 확인사항
- [ ] 서버 재시작 완료
- [ ] 브라우저 하드 리프레시 (Ctrl+Shift+R)
- [ ] 콘솔에 "✅ 비디오 로딩 성공" 메시지
- [ ] 네트워크 탭에서 200 상태 코드

### 비디오 형식별 테스트
- [ ] **MP4 파일**: 모든 브라우저에서 작동해야 함
- [ ] **MOV 파일**: Safari에서만 확실히 작동
- [ ] **WebM 파일**: Chrome/Firefox에서 작동

### 브라우저별 테스트
- [ ] **Chrome**: MP4, WebM 지원
- [ ] **Firefox**: MP4, WebM 지원
- [ ] **Safari**: MP4, MOV 지원
- [ ] **Edge**: MP4, WebM 지원

## 🎬 권장 비디오 형식

### 최고 호환성 (모든 브라우저)
- **MP4 (H.264)**: 가장 안전한 선택
- **WebM (VP9)**: Chrome/Firefox에서 우수

### 제한적 호환성
- **MOV**: Safari에서만 확실히 작동
- **AVI**: 브라우저 지원 제한적

## 🚀 즉시 해결 방법

### 1. MP4로 변환
```bash
# FFmpeg 사용 (설치 필요)
ffmpeg -i input.mov -c:v libx264 -c:a aac output.mp4
```

### 2. 브라우저 변경
- **Mac 사용자**: Safari에서 테스트
- **Windows 사용자**: Edge에서 테스트

### 3. 다른 비디오 파일 테스트
- 작은 MP4 파일로 테스트
- 정상 작동하면 형식 문제, 안 되면 서버 문제

## 📱 모바일 고려사항

- `playsInline` 속성으로 전체화면 방지
- 터치로 재생 버튼 클릭 필요
- 데이터 사용량 고려하여 `preload="metadata"` 사용

문제가 지속되면 콘솔 에러 메시지와 함께 알려주세요!
