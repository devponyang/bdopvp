# PvP 커뮤니티 디자인 재설계

2026-11-04. 사용자 요청: 기존 화면 크기·배치·디자인에 구애받지 않고 PvP 전적 사이트와 게이밍 커뮤니티에 맞게 재설계한다.

## 의견 조사와 한계

직접 받은 사용자 피드백은 없다고 확인했다. 아래는 공개된 타 서비스 이용자의 개별 의견이며 포냥이 이용자 조사나 대표 표본이 아니다. 오래된 게시물도 있어 현재 서비스 상태를 평가하는 자료로 사용하지 않는다. 실제 사용자에게 메시지를 보내거나 설문을 실시하지 않았다.

| 공개 의견 | 설계에 반영한 판단 |
|---|---|
| [OP.GG 커뮤니티의 로딩 화면 시안 의견](https://talk.op.gg/s/lol/free/456377/%EC%98%A4%20%EB%A1%A4%20%EB%A1%9C%EB%94%A9%ED%99%94%EB%A9%B4%20%EC%9D%B4%EB%A0%87%EA%B2%8C%20%EB%B0%94%EB%80%8C%EB%A9%B4), 2017: 외형 호평과 별개로 핵심 정보의 가독성 지적 | 강조색은 검색·선택·점수에 제한하고 정보의 위계와 글자 크기를 정리 |

| [Tracker 검색 문제 토론](https://www.reddit.com/r/marvelrivals/comments/1ibv4ix), 2025: 이름 검색 실패와 모바일 검색 혼란 사례 | 홈의 검색을 주 행동으로 배치하고 검색 대상 명시; 데이터 부재와 결과 없음 안내 유지 |

이 사례들에서 도출한 디자인은 설계자의 판단이며, 이용자들이 선택한 ‘최고 디자인’이라고 주장하지 않는다. 색상 선호는 조사로 검증되지 않았다.

## 선택한 방향

- 차콜 바탕, 따뜻한 흰색 글자, 오렌지 강조의 PvP 전적·커뮤니티 구성.
- 고정 사이드바를 제거하고 상단 내비게이션과 작은 화면용 접근 가능한 메뉴 사용.
- 홈의 주 행동은 가문·길드·클래스 통합 검색. 실제로 검색되는 클래스 바로가기 제공.
- 데이터가 유실된 현재는 저장된 공략과 커뮤니티 연결을 먼저 제공. 가짜 순위·최근 전적·인기 수치는 만들지 않는다.
- 랭킹 페이지는 읽기 쉬운 숫자, 명확한 필터, 표 내부 스크롤을 사용.
- 화면 너비는 고정 기기 크기에 맞추지 않고 유동 폭·Grid·clamp 기반으로 구성. 최대 읽기 폭만 제한.
- React 서버 컴포넌트에서 홈 데이터를 표시하고 메뉴·필터에만 클라이언트 상호작용 사용. 시각 효과용 새 라이브러리는 추가하지 않는다.
- 기존 스타일 위에 덧붙이는 방식 대신 공통 스타일시트를 교체. 공통 색상·간격·너비 변수를 사용.
- 키보드 초점, 본문 바로가기, 네이티브 dialog, 모션 감소 설정 유지.

## 검증

### 후속: 작성자 중심 공략 카드

21개 공략의 원문 작성자 소개에서 이름·소속·대표 이력을 옮겨 카드에 표시했다. `lib/portal/guide-authors.ts`가 메타데이터를 보관한다. 랭킹·소속은 실시간 정보가 아니므로 ‘작성 당시 소개 기준’으로 표시하고, 본문이 준비 중인 공략은 별도로 구분한다. 클래스·작성자·길드 검색을 지원한다. 카드 사진은 가로형으로 전체 비율을 유지한다. 320·390·1440px에서 작성자 표시·가로 넘침·iframe 작성자 검색을 브라우저로 검증했다.

- 프로덕션 빌드 및 TypeScript 검사 통과.
- 320 / 768 / 1024 / 1920px에서 홈·공략·랭킹·검색의 가로 넘침 없음 확인.
- 1440px 데스크톱·390px 모바일에서 주요 공개 페이지와 관리자 화면 검사 통과.
- 홈 검색 폼 실제 제출, 공략 검색·필터, 모바일 메뉴 열기·Escape·이동 확인.
- 메뉴 이동 뒤 로딩 완료를 기다려 랭킹 화면 캡처. 홈·모바일·랭킹 캡처 시각 확인.
- 브라우저 런타임 오류 없음. 관리자 인증·편집 및 접근 제한 검사 통과.
- 기존 입력·세션·게시 충돌 검사와 임베디드 PostgreSQL 검사 통과.
- Prettier 및 git diff 공백 검사 통과.

화면 캡처는 artifacts/home-desktop.png, artifacts/home-mobile.png, artifacts/ranking-mobile.png에 저장했다. 외부 디스코드·영상 서비스의 정상 동작과 실제 이용자 만족도는 로컬 검사 범위 밖이다. 운영 배포 및 실제 데이터 복구는 이번 디자인 변경에 포함하지 않았다.
