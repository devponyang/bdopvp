# 포냥이 전면 업그레이드 계획표

기준일: 2026-11-04. 기존 작업을 이어서 진행하며, DB 유실 상태를 기본 실행 조건으로 삼는다.

| 단계 | 범위 | 완료 기준 | 상태 |
|---|---|---|---|
| 1 | 핵심 의존성 및 실행 환경 | 레지스트리 안정 버전 확인, 호환성 해결, 잠금 파일 갱신 | 완료 |
| 2 | 프론트엔드 | 공통 디자인·모바일·공략 상세·검색·필터 검증 | 후속 디자인 전면 재설계 및 로컬 검증 완료 |
| 3 | 백엔드 | 인증, 검증, 충돌 방지, 운영 상태 API 테스트 | 완료 |
| 4 | 관리자 | 구조화 입력·수정·검증·게시·JSON 백업 검증 | 구현 및 로컬 검증 완료 |
| 5 | DB 및 운영 준비 | 비파괴 초기화 명령, 환경 예제, 복구 문서, CI | 구현·임베디드 DB 검증 완료 / 운영 연결 대기 |
| 6 | 통합 검증 | 타입, 단위/통합 테스트, 프로덕션 빌드, 실제 브라우저 | 로컬 검사 완료 / 운영 DB·원격 CI 미실행 |

## 원칙

- 실제 랭킹·전적을 만들거나 유실된 데이터가 복구됐다고 표시하지 않는다.
- 기존 공개 주소와 저장된 공략을 보존한다. 종료된 기능은 문서에서 구분한다.
- 새 관리 기능은 서버 권한 검사와 동일 출처 검사를 거친다.
- 패키지는 안정 배포 태그와 호환성을 확인한다. 모든 패키지의 무조건적인 메이저 변경은 하지 않는다.
- 완료 상태는 검증 결과가 나온 뒤 갱신한다.

## 코드 작업 외에 필요한 조건

새 DB 접속 정보와 운영 관리자 비밀값, 배포 계정, CDN/원본 서버 설정이 필요하다. 실제 DB 초기화·복원·배포·DDoS 방어 설정은 외부 환경 접근 없이 완료했다고 표시하지 않는다. 연결 정보가 없더라도 로컬 구현과 검증은 끝까지 진행한다.

## 검증 결과

- Next.js 16.4.5 Turbopack 프로덕션 빌드 성공.
- TypeScript 및 신규 모듈 Prettier 검사 성공.
- 입력 검증·세션 위조/만료·요청 크기 제한·트랜잭션 실패 롤백 검사 성공.
- 임베디드 PostgreSQL(PGlite)에서 실제 SQL 마이그레이션·게시·이력 보관·버전 충돌·이전 게시본 복원 성공. 네트워크 DB의 다중 연결 부하 검사를 대체하지는 않는다.
- 실제 Chromium에서 데스크톱/390px 모바일 주요 경로·검색·필터·메뉴·공략·관리자 편집 검사 성공.
- 한글 동적 경로의 URL 인코딩 표시 및 모바일 넘침 문제를 발견하여 수정 후 재검증.
- npm 보안 검사: 현재 설치 트리의 알려진 취약점 0건.
- 외부 영상/이미지 서비스는 브라우저 검사에서 차단했으므로 링크 유효성 검증 범위에서 제외.

화면 캡처는 artifacts/에 저장한다. 실행·검증·운영 안내는 README.md와 docs/rebuild.md에 있다.

## 후속 요청: PvP 전적·게이밍 커뮤니티 디자인

기존 디자인을 유지하지 않고 상단 메뉴·통합 검색 중심으로 다시 설계했다. 차콜·오렌지 색상, 유동 화면 폭, 클래스 공략·커뮤니티 우선 배치, 작은 전적 요약을 적용했다. 공통 스타일시트를 교체하고 로딩 화면의 이미지 순환·타이머를 제거했다. 공개 의견 출처와 해석의 한계는 [design-research.md](design-research.md)에 기록했다.

## 2026-11-05 공략 검색·공유 연결

- 공략 목록과 통합 검색이 `guide-search.ts`의 같은 검색 규칙을 사용한다. 클래스·작성자·길드 검색, 여러 단어 조합, 한글 NFC 정규화를 지원한다.
- 통합 검색의 공략 결과에 작성자와 소속을 표시한다. 빈 검색어는 기존대로 결과를 표시하지 않는다.
- 공개 공략 14개에 작성자, 설명, 대표 주소, 링크 공유 제목을 제공한다. 실제 작성일·수정일을 추정해서 넣지 않는다.
- 사이트맵에 공개 공략만 포함한다. 작성 예정 공략은 목록·통합 검색·사이트맵에서 제외한다.
- VM 설정·배포 환경은 변경하지 않는다.
- 검증: 프로덕션 빌드, 원문 보존, 공개 공략 전체 브라우저 검사, 작성자·복합어·분해된 한글 검색, 비공개 작성자 검색 제외, 사이트맵 공개 ID, 공략별 대표 주소·작성자·공유 제목 검사 통과.
